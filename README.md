# UrbanSense

UrbanSense is a digital twin system designed to simulate and predict city-level problems. It ingests public datasets to model the city as an interconnected system, allowing users to run "what-if" scenarios and view recommended interventions.

## Features

- **Dashboard**: Real-time overview of city metrics (Traffic, Air Quality, Energy, etc.).
- **Map View**: Interactive map visualizing data points and incidents.
- **Simulation**: Tools to predict future states based on different variables.
- **Recommendations**: AI-driven suggestions for city improvements.

## Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/dhanush290707/urbansense.git
    cd urbansense
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

## Deployment

To deploy the application to GitHub Pages:

```bash
npm run deploy
```
